# 📝 Lista de Tarefas

Aplicação web de lista de tarefas desenvolvida durante meus estudos de desenvolvimento Front-end.

O projeto permite adicionar e excluir tarefas, utilizando JavaScript para manipulação do DOM e `localStorage` para manter os dados salvos no navegador.

## 🚀 Funcionalidades

- Adicionar tarefas
- Excluir tarefas
- Validação de campo vazio
- Atualização dinâmica da interface
- Persistência das tarefas com `localStorage`
- Interface responsiva

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- LocalStorage
- Git e GitHub
